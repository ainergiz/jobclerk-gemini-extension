# Job Clerk

Job Clerk lists public physician jobs and medical events in Germany. Use
`suche_veranstaltungen` for courses, congresses and webinars. It returns the
match count, up to five upcoming events and the full filtered calendar. Use
the job tools for vacancies. Both use public data and require no account.

Cite the linked event or advert. Report fees, credits and job requirements
only when the organizer or employer has published them.
